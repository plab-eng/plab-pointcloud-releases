# P-LAB PointCloud — downloads

Instalador do **P-LAB PointCloud**, add-in de nuvem de pontos para Revit 2025 e 2026 (E57, LAS, LAZ, PTS, XYZ, RCP/RCS), feito pela P-LAB Engenharia.

**Baixar a versão mais recente:** [PLAB-PointCloud-Setup.exe](https://github.com/plab-eng/plab-pointcloud-releases/releases/latest/download/PLAB-PointCloud-Setup.exe)

Todas as versões e notas: [Releases](https://github.com/plab-eng/plab-pointcloud-releases/releases)

## Instalar
1. Feche o Revit.
2. Rode o instalador. Não pede administrador.
3. Abra o Revit: aba **P-LAB** › painel **Tools** › **PointCloud**.

Este repositório só distribui o instalador; o código-fonte não fica aqui.
